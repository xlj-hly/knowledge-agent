# 企业用户客户端

Vue 3 / JavaScript Options API。微信小程序使用微信登录，首次自动创建账号并设置随机默认密码，后续登录不会覆盖已改密码。H5 使用企业账号密码登录，账号由企业管理员创建；两端共用资料编辑、改密和退出。

## 结构与状态所有权

- `src/pages/index/index.vue` 拥有完整账号页面并组装客户端与控制器，接入 `onLoad`、`onShow`、`onUnload`；每次重新显示页面都先同步平台存储，即使旧操作尚未结束。同身份正在初始化时复用当前请求；中断的写入通过重新读取服务端账户确认最终状态，取消等待不代表写入回滚。
- `src/pages/index/state.mjs` 创建每个页面独立的账户状态，管理登录、资料、改密与退出流程；控制器接收状态与会话客户端，通过命名 API 操作访问账号接口，不依赖 Vue 组件实例、DOM 或平台全局对象。页面校验、样式和专属组件留在同一页面目录。
- `src/api/request.mjs` 封装 `uni.request` / `uni.uploadFile`、有界等待、平台存储、租户与会话隔离；账号接口及响应契约归 `src/api/account.mjs`。平台适配只依赖注入的 `uni` 能力，H5 hostname 读取限制在页面的 H5 条件编译分支。
- `src/api/wechat.mjs` 通过注入的 `uni.login` 取得一次性 code，处理超时和取消；页面卸载或身份改变后丢弃迟到结果。code 只用于本次服务端登录请求，不写入存储。
- `src/pages/index/components` 保存微信登录入口、认证表单、账户主页、资料和密码表单。组件接收 props，通过事件更新控制器持有的草稿；共享样式在各组件内按 scoped 方式编译，兼容小程序组件样式隔离。

当前只在 `pages.json` 中配置了一个账号页面，页面控制器拥有交互状态；没有预建跨页面 Store 或 composables，继续使用 Options API。

会话客户端拥有令牌及平台持久化，控制器拥有授权视图与用户/租户名下的所有表单草稿。用户、租户或令牌变化及会话失效时，先撤销旧请求归属并清空旧视图与草稿，迟到响应不能写入新账号；恢复身份后按字符串 ID 校验租户归属，保留 BIGINT 精度。登录响应必须未过期才能保存，授权视图建立前再次检查有效会话，防止保存期间到期后恢复旧视图。存储读写失败显示可重试错误；失效通知先撤销内存身份，删除存储失败不会阻断通知和请求结束，也不会在当前客户端恢复已撤销的旧令牌。

## 开发

```sh
npm install
npm run dev:h5 -- --host 0.0.0.0
```

H5 默认使用当前页面的 hostname 解析企业，API 使用 `/api`。Vite 将 `/api` 代理至本地 Go 服务 `http://127.0.0.1:8080` 并保留外部请求 Host。需要先由平台创建对应 hostname 的企业；前端不预置演示账号。生产 H5 使用 HTTPS 和同域 API 反向代理。

开发时可通过环境变量 `API_PROXY_TARGET` 指定其他后端地址，例如 `http://127.0.0.1:8081`。该设置只影响 Vite 代理，不进入客户端包。

小程序在本地 `.env.local` 设置公开连接信息，然后重新编译：

```dotenv
VITE_API_BASE_URL=https://company.example.com/api
```

API 地址须包含 `/api`，从实际请求地址的域名确定企业；H5 同源相对地址使用当前页面域名。每家企业的小程序访问自己的域名，由保留 Host 的 HTTPS 反向代理转到 SaaS 后端；在微信平台配置对应合法请求和上传域名。客户端不发送租户选择请求头，也不支持 `VITE_TENANT_HOSTNAME` 覆盖。

微信小程序构建通过 `process.env.UNI_PLATFORM` 使用微信登录入口。用户点击后调用 `uni.login` 获取临时 code，提交 `POST /api/auth/wechat/login`，服务端验证后才保存本系统令牌。首次登录在本企业创建普通成员；已有微信成员恢复同一账号。首次进入不强制补全头像、昵称或密码；用户可在账号页设置自己的密码，并在个人资料页按需选择微信头像及填写昵称。

小程序 AppID 由 `manifest.json` 的现有配置维护；对应 AppSecret 由平台在企业的小程序配置中维护，仅由后端使用，配置方式见 [服务端 README](../server/README.md)。客户端不携带 AppSecret、OpenID 或 session_key。H5 保留用户名密码流程，微信创建账号的随机默认密码不下发；用户在小程序设置密码后，可使用用户名和自己设置的密码登录 Web。

## 验证

```sh
npm test
npm run build:h5
npm run build:mp-weixin
```

`npm test` 使用 Vitest 1.6、Vue Test Utils 2、Vue 编译器插件 5 与 jsdom 24，匹配现有 Vite 5 / Vue 3。常规命令自动发现 `tests/` 与 `src/` 下的 `*.test.js` / `*.test.mjs`，没有仅运行旧文件的固定清单。

API 测试靠近请求与账号接口实现，覆盖企业隔离、认证请求、失效与旧响应竞争、取消、错误响应、输入边界及平台存储读/写/删失败；表单纯校验测试跟随页面。页面流程由 Vue 编译器加载并实际挂载完整 `index.vue` 组件树，通过表单输入与按钮事件执行真实控制器，覆盖登录入口、登录取消、PUT 资料保存、改密退出、退出重试、停用、跨身份恢复、旧表单与响应失效、非法身份响应拒绝，以及登录前后到期。平台替身只向实际页面实例分发 `onLoad` / `onShow` / `onUnload`，确认忙碌状态仍核对身份和重新读取服务端结果。不提取源码或复制方法，不以普通对象模拟 Vue 实例；API 与存储边界由 `uni` 替身隔离。

微信适配测试覆盖平台拒绝、回调不返回、无效 code、取消和迟到结果；页面套件通过同一平台常量运行微信入口，验证服务端确认前不保存会话、失败重试、企业响应契约、密码设置入口、头像上传与原生昵称表单提交、上传跨用户响应拒绝、存储失败、身份替换与页面卸载后的结果失效。微信平台 API 在这些用例中使用替身，真实 code2Session 联调单独报告，不能由构建或组件测试替代。

这些用例属于单元/组件及页面适配验证，未贯通真实后端，也不验证 uni-app 对原生生命周期的实际分发和目标端事件实现。真实 H5 用户闭环由仓库 `react-app/e2e/saas.spec.ts` 的 Playwright 用例连接真实 Go 服务及隔离 PostgreSQL 验证；其执行与结果单独记录。H5 与微信构建只验证对应编译链，不能替代小程序模拟器或真机验证。

登录令牌通过 `uni` storage 按 API 地址与企业域名隔离保存。重新显示页面时检查服务端登录状态；401 或过期会回到登录视图。退出请求失败保留当前登录状态并允许重试；改密成功后清空登录状态，所有设备会话由后端撤销。

资料保存使用 `PUT /api/account/profile`，完整提交 `nickname` 与 `avatar_url` 两个字段。缺省字段、`null` 和空对象拒绝；空字符串显式清空对应字段。接口契约与部署说明统一见 [`docs/saas.md`](../docs/saas.md)。


## 微信头像昵称与头像上传

小程序资料表单通过 `button open-type="chooseAvatar"` 接收用户主动选择的头像临时路径，通过 `input type="nickname"` 显示微信提供的昵称建议；昵称使用原生 form submit 的最终值，避免平台异步检测清空后仍提交旧草稿。H5 使用 `uni.chooseImage` 选择图片。头像与昵称都可在登录后按需设置，不阻塞首次进入。

头像通过 `POST /api/account/avatar` 上传，multipart 字段名为 `file`，使用当前企业会话 Bearer。支持 JPEG / PNG，最大 2MiB；成功响应为 `{data:{avatar_url:"/api/avatars/<tenant_id>/<user_id>/<随机文件名>.png|jpg"}}`。客户端核对上传地址归属当前用户，再将地址放入资料草稿，点击保存资料后更新账号。相对图片地址从 API origin 解析，避免 API 已含 `/api` 时重复拼接。临时文件地址不作为长期资料保存，上传后未保存的草稿不会覆盖当前账号头像。

上传与普通请求共享 15 秒超时、取消、会话失效和身份变化处理。页面卸载或切换账号后，旧上传结果不能修改新账号的草稿。昵称建议、原生头像选择和微信侧检查的真实交互仍需微信模拟器或真机验证；jsdom 测试通过实际 Vue 表单与受控平台事件验证保存流程。


微信小程序的改密表单只要求新密码与确认密码，内部通过新的 `uni.login` code 和现有 Bearer 会话调用 `POST /api/account/wechat/password`，服务端验证两种身份属于同一用户后才修改密码并撤销会话。随机默认密码不显示给用户。H5 继续使用当前密码、新密码和确认密码，以及原有 `POST /api/account/password` 接口。
