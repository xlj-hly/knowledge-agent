# 企业聊天与管理工作台

React 19、TypeScript、Vite 8、React Router、Zustand 5。平台与企业使用独立入口和登录会话，企业首页是聊天，知识库和 AI 配置独立管理。业务与接口见 [SaaS 说明](../docs/saas.md) 和 [知识库与聊天说明](../docs/knowledge.md)。

Docker 使用 Node 构建静态文件、Nginx 提供页面与同域 API 转发，详见 [部署说明](../deploy/README.md)。

## 启动

```powershell
npm install
npm run dev
```

Vite 将 `/api` 代理到 `http://127.0.0.1:8080`，保留 Host。需要其他地址时在启动前设置：

```powershell
$env:API_PROXY_TARGET = 'http://127.0.0.1:8081'
npm run dev -- --host 0.0.0.0
```

浏览器先通过 `/api/site` 发现当前域名对应的平台或企业入口；后端根据实际 HTTP Host 识别，客户端不发送租户选择头。企业域名不能进入平台管理，未绑定域名不提供登录。本地可将 `platform.localhost` 配入后端平台域名白名单，用 `localhost` 或其他 `.localhost` 子域名开通企业；开发代理及生产代理均需保留 Host。`location.hostname` 只用于隔离当前域名的会话存储。

## 路由

| 地址 | 入口与权限 |
| --- | --- |
| `/login` | 企业成员登录 |
| `/`、`/chat/:id` | 新建对话、历史对话、知识问答与来源 |
| `/overview` | 企业概览 |
| `/account` | 企业成员个人资料、密码 |
| `/knowledge`、`/knowledge/:id` | 企业知识库、资料、分块及检索测试 |
| `/models` | 企业管理员配置 LLM、发现模型、测试当前表单并启用唯一聊天模型 |
| `/embedders` | 企业管理员配置 Embedder 并检测输出维度 |
| `/ai-settings` | 企业管理员配置新建默认值、System Prompt、切分与检索 |
| `/vector-stores` | 企业管理员按引擎配置向量连接并测试 |
| `/members` | 企业管理员管理成员、角色、状态与密码 |
| `/settings` | 企业管理员维护企业信息 |
| `/platform/login` | 独立平台管理员登录 |
| `/platform` | 平台工作台 |
| `/platform/tenants` | 开通、维护企业，配置小程序，重置企业管理员密码 |
| `/platform/account` | 平台账号与密码 |

BrowserRouter 以 URL 作为页面状态；导航使用 Link / NavLink，支持直接访问、刷新、前进与后退。未登录访问业务地址会进入对应登录页，登录后只恢复白名单内且属于当前身份空间的地址。普通成员直接访问管理页显示无权访问；未知地址显示页面不存在，并提供返回工作台的入口。前端路由守卫用于界面组织，不能代替服务端权限检查。

平台首位管理员需要后端显式 bootstrap，没有默认账号和密码。平台路由仅在平台域名开放，该域名的根地址进入 `/platform`。平台会话与企业会话按域名分别保存，切换身份空间会销毁旧请求与页面状态。

平台企业列表中的“小程序配置”维护对应企业的 AppID 与 AppSecret，没有额外登录开关。平台授权配置接口返回 `{app_id,app_secret}` 原值并回填表单；保存完整提交两项，缺失或空值拒绝，不继承旧密钥。配置草稿不持久化到浏览器。保存后根据服务端确认刷新，重新打开时读取当前配置；公共站点、用户资料和微信登录响应不包含 AppSecret 或微信 session_key。

## 配置、知识库与聊天

LLM 与 Embedder 分别配置，提供服务商地址和候选模型预设、远端模型发现与手填、真实调用测试；测试不要求先保存，直接使用当前表单中的凭据，不提交已存 ID 回读密钥。企业管理员在 LLM 列表启用唯一聊天模型，聊天页不提供模型选择。企业默认配置提供 Prompt 和切分预设、默认 Embedder 与向量连接，保存时不提交或覆盖当前启用 LLM。预设不代表实际服务已部署。已有授权接口返回模型 `api_key` 和完整向量 config 并回填表单；保存按提交完整替换，空值直接生效，必填字段为空时拒绝，不继承旧值。凭据不写入静态包、浏览器持久化或日志。

配置交互使用 Ant Design，中文语言与主题由浏览器入口统一组装。侧栏是跨页导航入口，配置页不重复提供跨菜单 Tab。模型服务商可按名称和描述搜索，点击卡片即可配置；名称、Logo、说明、能力、地址、候选模型、凭据提示与发现支持全部消费后端注册目录，前端不维护品牌映射。向量页同样从 `/api/knowledge/vector-providers` 读取引擎定义与连接字段，动态生成 13 种引擎的配置表单。服务端内嵌品牌资源由 API 返回受控 data URI，第三方来源记录在服务端资源目录；许可证保留于 `public/licenses` 随 Web 交付。

企业默认配置以五组摘要展示，点击编辑后在抽屉内修改一组；保存该组会合并最近已保存的完整配置，取消不会改变服务端。提示词、生成参数、检索与文本分割无需在同一长表单内处理。

企业 Prompt、生成、检索以及知识库处理模板只影响新建对象，已有知识库和会话独立维护对应配置。启用 LLM 在每次发送时读取，新旧会话的下一条消息都使用当前启用模型，正在流式的回答继续使用开始时捕获的模型。会话请求不提交 `model_id`，响应中的该字段只是最近生成模型快照。知识库默认建立关键词与向量索引，缺少连接时提示配置；也可明确选择只用关键词。查询策略在已有索引中切换无需重建；模型、向量、解析或切分变更需要确认重建整库，保留原件但重新生成分块。页面提供与后台一致、无写入的切分预览。

Prompt、切分方案及策略名称、说明、选项统一读取 `/api/ai/presets` 的 `prompts`、`chunking`、`chunk_strategies`，页面不维护第二份策略映射。模型、向量及产品预设按各自能力读取目录，前端只维护受控组件和表单状态。

聊天沿用标准侧边文字导航、顶部栏和页面内容区，在内容卡片内恢复本用户历史，支持普通对话或选择知识库问答。用户消息气泡靠右、头像在右，AI 回答靠左、头像在左；正文保持左对齐，用户文本保留换行并自动折行，AI 代码块与表格在内部横向滚动。历史、流式和窄屏保持同样的角色排布。

空态的输入框位于聊天卡片中央，已有消息时位于卡片底部；Enter 发送，Shift+Enter 换行，中文输入法选字不会误发送。历史和流式回答统一安全渲染 Markdown，回答支持复制，来源快照在抽屉查看；接近底部才自动滚动，向上阅读时不会被 token 拉回。会话设置修改仅影响后续消息；生成中支持停止，失败和停止保留已有文本。流式状态与输入草稿属于当前页面，权威消息历史保存在服务端，不写入 Zustand 持久化。详细操作和配置范围见 [知识库与聊天说明](../docs/knowledge.md)。

## 代码组织

- `src/main.tsx`、`src/App.tsx`：浏览器挂载、BrowserRouter 与身份空间组装。
- `src/router`：登录与受保护路由、权限入口和导航规则。
- `src/layouts`：应用布局、导航展示与布局样式；由路由层传入导航模型。
- `src/pages`：聊天、知识库、模型、Embedder、AI 设置和 SaaS 的完整页面；专属表单、弹窗、Hook、样式和测试跟随页面。
- `src/api`：按认证、账号、企业、AI、知识库、聊天划分契约和解码；统一用 fetch 处理 JSON、下载和 SSE，集中管理超时、取消、认证与同源策略。
- `src/stores/session`：按身份空间创建的 Zustand 会话 Store、持久化、Hook 与身份类型。
- `src/components`、`src/hooks`、`src/utils`：跨页面组件、异步生命周期及具有明确用途的公共函数。

路由组合完整页面与布局，页面调用 API、会话和公共组件。页面之间不读取私有实现；接口类型与响应解码由相应 API 维护，跨页面使用的账号校验具有独立维护位置。请求层通过参数与失效回调接入会话，不反向导入 Store。布局只消费导航模型，不依赖导入页面的路由注册模块。

Zustand Store 拥有内存会话，`persist` 配合 `createJSONStorage` 将令牌保存到当前标签页的 sessionStorage，平台与不同企业使用独立键。持久化只白名单保存 `token`，身份资料由后端重新确认；版本号、提示、请求状态、表单与密码草稿不持久化。恢复只接纳有效的令牌字段，存储内容不能覆盖动作和运行时状态。表单和弹窗继续使用组件局部状态。

存储失败会显示提示，仍能在内存中完成登录或退出。401 或停用会清理当前会话；普通权限不足保留登录并显示拒绝原因；旧身份响应不能清理新登录。普通请求期限为 15 秒，包含正文读取；对话流使用独立的 150 秒无数据期限，支持停止及卸载取消。离开页面、切换身份或显式新建/重置都会失效旧请求，即使 URL 不变；过期会话创建不能触发跳转或继续发送。取消写入不代表回滚，重新进入页面时读取服务端确认。

个人资料统一使用 PUT，完整提交 `nickname` 和 `avatar_url`，空字符串清空。头像从文件选择器选取 JPG/PNG，最大 2MB；保存时先通过带认证的 multipart 上传，再将服务端返回的同源相对路径绑定到资料。重新读取或仅修改昵称时保留该路径。所有新密码按 UTF-8 的 10–72 字节校验。

## 验证

```powershell
npm test
npm run build
npm run lint
```

Vitest 自动发现 `src/` 和 `tests/` 下的 `*.test.{ts,tsx,mjs}`；`npm run test:watch` 可交互运行。局部测试靠近实现，跨业务客户端与应用路由流程放 `tests/integration`，迁移后的 TSX 流程测试仍纳入 TypeScript 检查；Node 测试使用 Node 工具配置检查。React Testing Library 实际挂载组件、Hook 和路由，验证输入、会话持久化与恢复、草稿、请求取消、登录恢复、权限及浏览器历史对应的路由行为。局部测试使用 HTTP 或平台替身隔离后端，不能代替产品贯通验证。

真实产品流程由 Playwright 连接 Go API、GORM、隔离 PostgreSQL、React 和 uniapp H5 执行：

```powershell
npx playwright install chromium
$env:SAAS_TEST_DATABASE_URL = 'postgres://用户:密码@localhost:测试端口/测试库?sslmode=disable'
npm run test:e2e
```

测试启动端口 8081、5175、5176，平台入口使用 `platform.localhost:5175`，企业入口使用 `localhost:5175`。按本次运行标识确认 API 实例，在随机 schema 导入 `db/saas.sql` 并初始化测试身份，结束后清理。不会使用开发环境的 DATABASE_URL。需要 Go、两端前端依赖及空闲测试端口。

SaaS 流程覆盖平台开通、小程序配置与企业隔离、管理员建号、双端资料与改密、停用恢复、会话撤销、路由历史及跨域名状态清理。知识库与聊天回归范围包括模型及模板配置、唯一 LLM 启用、新旧会话后续发送、资料导入、分块与检索、重建、对话生成、引用和刷新恢复，以及输入框、Markdown、复制、来源抽屉与滚动交互。桌面、刷新恢复和 390px 窄屏通过真实元素位置验证用户右、AI 左及头像顺序，并检查用户长文本与长链接不撑宽页面。自动流程中的模型服务可使用受控上游，界面、业务 API 与 PostgreSQL 仍执行真实实现；不据此声称真实模型效果已经验收。真实向量服务按测试的明确配置单独覆盖；微信配置流程不调用真实微信上游。失败截图与 trace 保存在忽略的 `test-results/`。

生产将 `dist` 部署到 HTTPS 站点，业务路径回退到 `index.html`，`/api` 独立反向代理到 Go 服务且不走 SPA 回退；不要将后端秘密写入前端环境变量。
