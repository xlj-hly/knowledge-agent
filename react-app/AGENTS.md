# React 与 TypeScript 编码规范

### WEB-001：保持组件职责清晰

- 沿用已有目录与模块边界，组件职责集中，复杂计算和请求处理放在有明确语义的函数或模块中。
- 有实际复用时再提取公共能力，避免过度抽象和循环依赖。

### WEB-002：遵循组件与 Hook 规则

- 渲染保持纯粹，不修改 props、state 或外部共享值，派生值优先直接计算。
- 普通 Hook 只在组件或自定义 Hook 顶层调用；React `use` 的特殊调用方式遵循其 API 约束。
- Effect 用于同步外部系统，声明实际依赖，清理监听、订阅与计时器。

### WEB-003：保持类型安全

- 为组件输入、事件和业务数据定义清晰类型；外部未知值使用 `unknown`，缩小类型后使用。
- 不用 `any`、非空断言或强制转换掩盖缺失校验，必要断言应具有可信前提并限制范围。
- 遵循项目编译选项，纯类型导入使用 `import type`。

### WEB-004：明确数据边界

- 调用遵循现有接口，修改数据结构时同步检查使用方。
- 传输处理与渲染逻辑分开，对外部数据执行必要校验并处理异常值。
- 服务端秘密不得进入客户端包或公开配置，日志排除敏感信息。

### WEB-005：处理异步错误与过期结果

- 异步操作明确处理失败，避免吞掉异常。
- 取消已失效请求或忽略过期结果，避免旧响应覆盖新状态、卸载后继续更新状态。

### WEB-006：限定样式影响

- 样式靠近所属组件，使用项目已有命名与尺寸约定。
- 修改全局选择器或共享样式时检查影响范围，避免无关页面受到污染。
