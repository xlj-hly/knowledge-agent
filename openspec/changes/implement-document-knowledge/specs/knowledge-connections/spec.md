# Spec Delta

## Purpose

允许企业管理员从页面配置向量数据库连接，明确凭据、归属、引用和旧索引清理责任；模型连接由 AI 配置能力统一管理。

## ADDED Requirements

### Requirement: 向量引擎定义和驱动注册

系统 SHALL 显式注册向量引擎元数据、连接字段、默认值、校验和真实驱动，通过已鉴权目录接口提供给页面；连接校验和向量操作使用同一目录。领域及知识处理流程 MUST 不按引擎品牌分支。构建时拒绝重复定义，调用时拒绝未知引擎。实际注册 13 个远程引擎模块：Qdrant、PGVector、Chroma、Chroma Cloud、Pinecone、Milvus、Zilliz Cloud、Weaviate、AstraDB、Elasticsearch、OpenSearch、Doris、Tencent VectorDB，同协议 MUST 复用驱动。

#### Scenario: 页面读取引擎目录
- **WHEN** 管理员进入向量连接页面
- **THEN** 页面读取已注册引擎的名称、说明、Logo 和字段定义生成对应表单，不维护本地品牌列表或品牌字段分支

#### Scenario: 分派未知引擎
- **WHEN** 配置或索引请求指定未注册引擎
- **THEN** 请求明确失败，不回退到 Qdrant 或执行其他驱动

### Requirement: 向量存储页面配置

系统 SHALL 提供各已注册引擎连接的创建、授权完整读取、完整表单更新、删除与实际连接测试。连接 config MUST 使用明确字符串值并拒绝未知字段、null 和错误类型。其他企业及普通成员不得管理连接；已有读取权限保持。已授权配置响应 MUST 返回完整 config，包括实际凭据，不使用 configured_secrets 或 PublicStore 过滤。保存按提交完整替换，不合并旧字段或继承旧凭据；空串直接生效，必填字段缺失或为空时拒绝。secret 元数据 SHALL 用于输入类型及默认值约束，不过滤配置响应；凭据不得进入静态包、未授权接口、浏览器持久化或日志。

#### Scenario: 完整替换与凭据清空
- **WHEN** 管理员保存完整 config 并清空可选凭据或移除可选字段
- **THEN** 原值不被合并或继承，保存结果仅采用本次提交；必填字段缺失或为空时拒绝且原记录保持不变

#### Scenario: 引擎执行真实索引
- **WHEN** 用户通过所选引擎导入资料并执行检索、清理旧处理代
- **THEN** 驱动使用真实协议并始终限定企业和知识库归属，旧代清理不删除其他资料和新处理代

#### Scenario: 配置并测试连接
- **WHEN** 企业管理员保存地址、集合前缀和凭据并测试
- **THEN** 服务实际访问向量数据库，授权配置读取返回完整 config，页面重新读取能够回填已保存凭据与其他配置

#### Scenario: 连接隔离
- **WHEN** 普通成员或其他企业尝试修改连接
- **THEN** 操作被拒绝，连接及原有数据保持不变

### Requirement: 向量连接引用保护

系统 SHALL 拒绝删除仍被知识库、企业默认模板、当前处理代或待清理旧索引引用的连接；已使用连接不能原地更换索引地址或集合标识。引用创建与删除 MUST 通过同企业应用事务协调，不能依赖数据库外键。

#### Scenario: 删除仍需清理的旧连接
- **WHEN** 知识库已切换新连接，但旧连接仍有待清理处理代
- **THEN** 旧连接删除被拒绝，恢复清理成功并移除其他引用后才允许删除

#### Scenario: 替换已使用连接
- **WHEN** 管理员需要变更已被资料使用的向量服务
- **THEN** 创建新连接并在知识库确认整库重建，不原地改变旧索引的地址归属

### Requirement: 向量检索归属复核

系统 SHALL 在外部向量查询中限定企业和知识库，并在 PostgreSQL 复核命中分块的资料及当前完成代。向量维度 MUST 与所选 Embedder 一致，不截断补齐或返回伪造结果。

#### Scenario: 旧代向量暂留
- **WHEN** 外部查询命中过时、已删除或其他企业的分块 ID
- **THEN** 该结果不返回给用户，合法的当前完成代才可参与排序与问答
